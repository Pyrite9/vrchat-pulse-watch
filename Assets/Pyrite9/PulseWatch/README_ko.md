# Pyrite9 Pulse Watch

버전 0.1.0 (2026-10-30)

VRChat 아바타용 팝업형 손목시계 기믹입니다. 휴머노이드 아바타에 프리팹을 넣기만 하면 빌드할 때 그 아바타의 팔뚝에 시계를 맞춥니다.
손목을 시계 보듯 눈 쪽으로 돌리면 손목 위에 홀로그램이 펼쳐집니다 — 착용자 시각, 주변 레이더, 스캔 파동, 손가락으로 누르는 웨이포인트·손전등 버튼. 손목을 치우면 접힙니다.

English: `README_en.md` / 日本語: `README_jp.md` / 이용 규약: `LICENSE.txt`

## 기능

- 손목을 눈 쪽으로 돌리면 시계 위에 홀로그램이 열림 — 시각·날짜·레이더. 데스크톱은 메뉴 **계속 열기**
- 레이더: 14 m 안 주변 사람을 12방향 × 5거리 격자로, 찬 칸 수와 함께 — 나에게만 보임
- 열 때 스캔 파동이 눈에서 14 m까지 바닥·벽·사람 위를 지나감 — 깊이 라이트로 어느 월드에서나(나에게만)
- 웨이포인트: 반대 손을 가리키는 자세로 시계 아래 버튼을 눌러 레이저를 켜고, 그 손 트리거로 바닥·벽·천장에 표지 — 나만, 또는 모두에게. 표지 위 이름표, 원판에 방향·거리
- 손전등: 버튼 하나 더 — 시계에서 내가 보는 쪽으로 스포트라이트, 나에게만 보임
- 원판 링에 나침반, 시계에 이 월드에 머문 시간
- 시계는 모두에게 내 시간대 시각과 월드 좌표를, 프레임 레이트는 나에게만
- 말하면 원판 바깥 고리가 빛나고, 음소거면 빨갛게 깜빡이며 마이크 표시
- 왼손·오른손, 손목 바깥·안쪽(둘 다 메뉴로 전환), 홀로그램을 남에게 숨기기
- 홀로그램 뒤는 유리 블러, 옆에서 보면 빛이 손목까지 흘러내림
- 빌드 때 아바타 팔뚝에 맞춤. 액센트 색·웨이포인트 색을 고를 수 있고, 기능마다 뺄 수 있음(뺀 기능은 빌드에 안 들어감)

## 필요한 것

- Unity 2022.3(VRChat)
- VRChat SDK – Avatars 3.10 이상
- Modular Avatar
- NDMF(Non-Destructive Modular Framework)

lilToon은 필요 없습니다(시계는 자체 셰이더를 씁니다).

확인한 환경: Unity 2022.3.22f1, VRChat SDK Avatars 3.10.5, Modular Avatar 1.18.7, NDMF 1.14.8.
이보다 오래된 버전과 프리뷰 버전(alpha·beta)은 확인하지 않았습니다.

- **PC 전용입니다.** 같은 아바타의 Android / Quest 판도 올린다면, Android로 빌드하기 전에 `PulseWatch` 오브젝트를 지우거나 꺼 두세요.
- 모든 기능을 켜면 아바타에 Light 2개(손전등·깊이 라이트)가 더해집니다. 필요 없는 쪽은 **넣을 기능**에서 뺄 수 있습니다(자세한 건 "참고").

## 설치

1. **필요한 패키지를 넣습니다.** VCC / ALCOM에서 아바타 프로젝트를 "관리"(Manage Project)로 열고 **Modular Avatar**를 추가합니다.
   NDMF는 Modular Avatar와 함께 자동으로 들어갑니다. 안정판(프리뷰가 아닌 버전)을 쓰세요.
   - 목록에 없으면 먼저 Modular Avatar 공식 사이트의 "Add to VCC"로 저장소를 추가하세요.
2. **이 패키지를 임포트합니다.** `.unitypackage`를 더블클릭(또는 Unity의 `Assets > Import Package > Custom Package…`)하고, 모두 체크한 채 **Import**를 누릅니다. 파일은 `Assets/Pyrite9/PulseWatch/`에 들어갑니다.

## 사용법

1. Project 창에서 `Assets/Pyrite9/PulseWatch/`를 열고 `PulseWatch.prefab`을 Hierarchy의 아바타(VRC Avatar Descriptor가 붙은 오브젝트)에 끌어다 놓습니다. 아바타의 자식이 됩니다.
   - **아바타 바로 아래(루트의 자식)에 두세요.** 뼈(Hips 등) 밑에 두면 데스크톱의 발밑 표지와 스캔 바닥이 그 뼈 높이로 뜹니다. **아바타 밖(씬 바로 아래 등)에 있으면 아무 일도 일어나지 않습니다.**
   - 프리팹을 Unpack하지 마세요(업데이트가 반영되지 않습니다).
2. Hierarchy에서 `PulseWatch`를 고르면 인스펙터가 나옵니다. 첫 구역(기본)의 **Menu language**(`EN` / `日本語` / `한국어`)에서 **한국어**를 고르면 인게임 메뉴·인스펙터·시계 날짜(`10.29 (목)`)가 한국어로 바뀝니다(기본값 EN — 날짜는 `THU 10.29`).
3. (선택) 다른 설정을 바꿉니다(아래 "설정"). 처음 차는 손목, 색, 넣을 기능 등.
4. 시험해 봅니다:
   - Unity에서 **Play**를 누르면 시계가 빌드되고 인스펙터의 **마지막 빌드**가 채워집니다(Play를 멈춘 뒤 표시). Play 모드에서는 손목 감지·메뉴가 동작하지 않으니 VRChat에서 확인하세요.
   - `VRChat SDK > Show Control Panel > Builder` → **Build & Test** 뒤 VRChat에서 테스트 아바타로 갈아입고, VR이면 시계를 찬 손목을 눈 쪽으로 돌려 봅니다. 데스크톱이면 **Pulse Watch** 메뉴에서 **계속 열기**를 켭니다.
   - 문제없으면 **Build & Publish**. Build & Test는 내 화면만 보여 줍니다 — 남에게 어떻게 보이는지는 (Private으로) 업로드한 뒤에 확인할 수 있습니다.
5. 결과를 확인합니다. 정상적으로 맞춰졌다면 **마지막 빌드**에 아바타 이름·빌드 시각·손목·크기와 **경고: 없음**이 나옵니다.
   - "아바타 안(VRC Avatar Descriptor가 있는 오브젝트 밑)에 넣어 주세요."가 나오면 시계가 아바타 밖에 있는 것입니다. 빌드한 뒤에도 "아직 빌드 기록이 없습니다"가 그대로 나오면 빌드가 시계까지 닿지 않은 것입니다(Console에 빨간 컴파일 오류가 없는지, 시계 오브젝트가 꺼져 있지 않은지 확인하세요).
   - 경고는 Console(`Window > General > Console`)에도 `[Pyrite9 Pulse Watch] WARN`으로 시작하는 노란 줄로 나옵니다 — "문제 해결"을 보세요. 자세한 내용은 프로젝트 폴더의 `Logs/Pyrite9_PulseWatch_build.txt`에 적힙니다.

빌드할 때 아바타의 팔뚝·손·머리를 재서 시계 자리와 크기(팔뚝 길이 비례), 손등 방향, 눈 위치, 레이저가 나오는 검지 끝을 맞춥니다. 씬은 바뀌지 않습니다 — 바뀌는 건 빌드용 사본뿐입니다.

## Expression Menu

메인 메뉴에 서브메뉴 **Pulse Watch** 하나가 추가됩니다(항목 이름은 **메뉴 언어**를 따르고, `Pulse Watch`라는 이름은 그대로):

| 항목 | 종류 | 파라미터 | 하는 일 |
|---|---|---|---|
| 계속 열기 | 토글 | `PulseWatch/Manual` | 손목 감지와 상관없이 홀로그램을 열어 둠. 데스크톱은 이걸로 엽니다 |
| 웨이포인트 ▸ 찍기 | 버튼 | `PulseWatch/WpTap` | VR: 레이저를 켬(시계 버튼을 누른 것과 같음). 데스크톱: 발밑에 표지 |
| 웨이포인트 ▸ 지우기 | 버튼 | `PulseWatch/WpClear` | 표지를 지움 |
| 웨이포인트 ▸ 남에게 보이기 | 토글(저장) | `PulseWatch/WpShow` | 켜면 남에게도 표지·이름표·레이저·원판 위 방향이 보임 |
| 손전등 | 토글 | `PulseWatch/Flash` | 손전등을 켬(시계 탭을 누른 것과 같음) |
| 남에게 숨기기 | 토글(저장) | `PulseWatch/Hide` | 켜면 남 화면에서 시계가 열리지 않음(내 화면엔 그대로). 웨이포인트는 이게 아니라 `남에게 보이기`를 따름 |
| 설정 ▸ 감도: 넓게 / 좁게 | 토글(저장) | `PulseWatch/Sens` | 여닫는 각도 4개를 +10° / −10°. 둘 다 끄면 보통 |
| 설정 ▸ 오른손에 차기 | 토글(저장) | `PulseWatch/Right` | 오른손목으로 옮김(기본값은 인스펙터의 **차는 손목**) |
| 설정 ▸ 손목 안쪽에 차기 | 토글(저장) | `PulseWatch/Inside` | 손바닥 쪽(택티컬 방식)으로 옮김 — 그때는 손바닥을 눈 쪽으로 돌려서 봄 |
| 설정 ▸ 디버그 막대 | 토글(저장) | `PulseWatch/Debug` | 인스펙터에서 **디버그 막대**를 켰을 때만 있음. 감지 각도 조정용. 처음엔 켜져 있음(막대 보임) |

손전등은 그 기능을, 웨이포인트 하위 메뉴는 웨이포인트 기능을 뺐으면 나오지 않습니다.

동기화 파라미터: **8비트**(`Open`·`Right`·`Hide`·`Inside`·`WpOn`·`WpSeq`·`WpLaser`·`WpShow`, 모두 `PulseWatch/` 아래, 웨이포인트를 빼면 4비트). 아바타 전체에서 256비트까지이고, 넘으면 SDK가 업로드를 막습니다.
저장되는 것: 감도·오른손·손목 안쪽·남에게 숨기기·남에게 보이기·디버그 막대 — 아바타를 다시 불러와도 유지됩니다. 계속 열기·손전등·표지는 저장하지 않습니다.

## 인게임 동작

| | VR | 데스크톱 |
|---|---|---|
| 열기 | 시계를 찬 손목을 시계 보듯 눈 쪽으로 돌려서 봄(시계 면이 눈 쪽 40° 안 + 시계가 시야 가운데 45° 안을 0.15초 유지). 치우면(55°·60° 밖) 접힘 | 메뉴 `계속 열기` |
| 웨이포인트 레이저 | 시계 없는 손을 **가리키는 자세**(검지만 편 손)로 하고 그 검지로 시계 판 아래 탭을 눌러 넣었다 뗌 → 그 손에서 레이저 | 없음 |
| 표지 찍기 | 레이저를 겨누고 그 손 **트리거** — 닿은 곳(바닥·벽·천장, 50 m까지)에 표지 | 메뉴 `웨이포인트 ▸ 찍기` — 발밑 |
| 표지 지우기 | 탭을 1.2초 누르고 있음(2초 안에 다시 누르면 취소) | 메뉴 `웨이포인트 ▸ 지우기` |
| 손전등 | 같은 자세로 웨이포인트 탭 옆 탭을 누름(다시 누르면 끔) | 메뉴 `손전등` |
| 손목 바꾸기 | 메뉴 `설정 ▸ 오른손에 차기`·`손목 안쪽에 차기` | 같음 |

- 표지는 떠다니는 마름모 + 이름표이고, 벽 너머로도 보입니다. 원판에는 표지의 방향과 거리가 나옵니다. 표지는 하나 — 새로 찍으면 옮겨집니다.
- 스캔 파동은 열 때마다 나오고(5초 안에 다시 열면 안 나옴), 1.4초 동안 눈에서 14 m까지 퍼집니다.
- 탭은 가리키는 자세일 때만 눌리기 시작합니다 — 손을 펴거나 쥔 채로 스쳐도 반응하지 않습니다. 이 손 모양에 표정을 붙여 둔 아바타는 누를 때 표정이 같이 바뀔 수 있습니다(아바타 FX의 제스처 표정).
- 시간대는 빌드한 PC의 시간대(또는 인스펙터에서 정한 UTC 차이)이고, 모두가 내 시계에서 같은 착용자 시각을 봅니다. **이 PC의 시간대**를 켜 두면 그 시간대의 서머타임 규칙(빌드한 해 기준)도 구워져 날짜에 맞춰 자동으로 바뀝니다. UTC 차이를 직접 넣으면 서머타임 없이 고정입니다.

- 남의 화면에서는 각자의 아바타 사본이 레이저를 쏴서 표지를 놓으므로 자리가 아주 조금 다를 수 있습니다. 늦게 들어온 사람에게는 다음에 찍을 때까지 표지가 보이지 않습니다.
- 메뉴 언어·색·위치·감지 각도는 빌드 때 아바타에 구워집니다.

## 설정(Pulse Watch 컴포넌트)

메뉴 언어를 한국어로 했을 때 인스펙터에 보이는 이름입니다. 게이지는 더블클릭하면 기본값으로 돌아갑니다.

| 구역 | 항목 | 뜻 |
|---|---|---|
| 기본 | 메뉴 언어 | `EN` / `日本語` / `한국어` — 메뉴 표시·시계 날짜(`THU 10.29` / `10.29 (木)` / `10.29 (목)`, 빌드 때 적용)와 인스펙터 언어. 기본값 EN |
| | 차는 손목 | 왼손(기본값) / 오른손 — 처음 차는 손목. 메뉴 **설정 ▸ 오른손에 차기**로 플레이 중에 바꿀 수 있습니다(저장됨) |
| | 액센트 색 | 홀로그램의 강조색(바늘·게이지·강조)과 스캔 파동. 기본값 노랑 #FFE00D, **기본** 버튼으로 되돌림 |
| | 웨이포인트 색 | 웨이포인트 레이저·표지·이름표·조준점, 원판의 화살표와 웨이포인트 버튼. 기본값 하늘색 #4CD9FF. 홀로그램은 어두운 유리 위의 빛이라 **어두운 색은 흐리게 보입니다**(인스펙터가 경고) |

| | 스캔 | 열 때 파동 — FX 레이어 1개 |

## 문제 해결

Console 경고는 영어로 나옵니다. 인스펙터 **마지막 빌드**에도 같은 영어 문장이 나옵니다.

| Console 메시지(`[Pyrite9 Pulse Watch] WARN …`) 또는 증상 | 할 일 |
|---|---|
| 임포트 직후 `error CS0246: The type or namespace name 'nadena' could not be found` 같은 빨간 오류가 나고 Play·빌드가 안 됨 | Modular Avatar(및 NDMF)가 설치되지 않았습니다. VCC / ALCOM에서 Modular Avatar를 추가하면 Unity가 다시 컴파일한 뒤 오류가 사라집니다. |
| `not a humanoid avatar — watch not built` | 휴머노이드 아바타(Rig: Humanoid, 루트에 VRC Avatar Descriptor)만 지원합니다. |
| `head bone missing — watch not built`, `lower arm / hand bone missing — watch not built` | 아바타의 휴머노이드 본 매핑(머리·아래팔·손)을 확인하세요. |
| `L/R: index / little finger bones missing — back of the hand assumed …`, `L/R: back of the hand undefined — using up` | 손가락 본이 없어 손등 방향을 짐작했습니다. 시계가 손목 옆이나 안쪽에 붙어 보이면 손가락 본 매핑을 확인하세요. |
| `L/R: index finger bones missing — the laser starts … past the hand` | 검지 본이 없어 레이저가 손 앞에서 나옵니다. 동작은 합니다. |
| `name tag: no font has "…" — left out of the tag` | 이름의 그 글자를 그릴 글꼴이 이 PC에 없어 빼고 구웠습니다. 다른 이름을 쓰거나 그 글자를 빼세요. |
| `the watch is under the armature (…) — put it right under the avatar root …` | 프리팹이 뼈 밑에 있습니다. 빌드는 되지만 데스크톱 발밑 표지와 스캔 바닥이 그 뼈 높이에 뜹니다. 아바타 루트 바로 아래로 끌어 옮기세요. |
| `… out of range — … used` | 인스펙터 숫자가 범위를 벗어나(직접 입력·스크립트) 가장 가까운 허용값으로 만들었습니다. 그 설정을 확인하세요. |
| `… Pulse Watches on one avatar — only the first is built` | 시계는 아바타에 하나만. 남는 것을 지우세요. |
| `shader … not found`, `glyph atlas missing …`, `… menu icons missing …`, `VRC… not found` | 패키지 파일이 빠졌거나 SDK가 너무 오래됐습니다. 패키지를 다시 임포트하고, 안 되면 VRChat SDK를 업데이트하세요. |
| `Build error: …`(마지막 빌드), Console에 빨간 오류 | 시계가 빠졌습니다(아바타의 나머지는 빌드됨). 빨간 오류와 `Logs/Pyrite9_PulseWatch_build.txt`를 보내 주세요("문의"). |
| Pulse Watch 메뉴가 안 보임 | 프리팹이 아바타 밖에 있거나, 시계 오브젝트가 꺼져 있거나, "— not built" 경고로 빌드가 멈췄습니다(위 표). 고친 뒤 다시 빌드·업로드하세요. |
| 메뉴·날짜가 영어로 나옴 | 인스펙터의 **Menu language**를 **한국어**로 바꾸고 다시 빌드하세요. |
| VR에서 손목을 봐도 안 열림 / 너무 쉽게 열림 | 메뉴 **설정 ▸ 감도: 넓게**(안 열릴 때)·**좁게**(너무 쉽게 열릴 때). 더 맞추려면 인스펙터 **감지**의 각도를 바꾸고, **디버그 막대**를 켜서 VR에서 막대를 보며 맞추세요. 손목 안쪽에 찼다면 손바닥을 눈 쪽으로 돌려야 열립니다. |
| 데스크톱에서 안 열림 | 데스크톱은 손목 감지가 안 됩니다. 메뉴 **계속 열기**를 켜세요. |
| 시계 면이 소매에 묻힘 | Pulse Watch 오브젝트를 선택하면 Scene 뷰 손목에 원판 자리가 보입니다 — 어느 쪽에서 봐도 빨갛다면 소매 안입니다. 인스펙터 **위치 ▸ 시계 면 높이**를 올리세요(원판이 바로 따라 움직입니다). |
| 탭을 눌러도 반응이 없음 | 시계 **없는** 손을 가리키는 자세(검지만 편 손)로 하고 그 검지 끝으로 탭을 눌러 넣었다 떼세요. 펼친 손·주먹으로는 눌리지 않습니다. |
| 레이저를 켰는데 표지가 안 찍힘 | 레이저를 쏜 손의 트리거를 당기세요. 50 m 안에 닿는 면이 있어야 합니다. 레이저는 10초 동안 안 쏘면 저절로 꺼집니다. |
| 레이더에 아무도 안 나옴 | 레이더는 다른 사람의 머리 Contact를 잡습니다. 14 m 안에 사람이 있어야 합니다. 남 화면에서는 원래 빈 원판입니다. |
| 스캔 파동이 바닥·벽을 따라가지 않고 고리만 나옴 | **깊이 라이트**가 꺼져 있으면 깊이 텍스처가 없는 월드에서는 고리와 바닥 격자만 나옵니다. 거울과 직교 카메라에서는 표면 스캔이 나오지 않습니다. |
| 특정 월드에서만 손전등이 아주 빠르게 켜졌다 꺼졌다 함(가만히 있어도) | 그 월드의 실시간 라이트가 Unity가 물체 하나에 비출 수 있는 수보다 많고 월드 조명도 계속 바뀌어서, Unity가 프레임마다 고르는 라이트에 손전등이 들어갔다 빠졌다 하는 것입니다. 월드 쪽 라이트 한도라 아바타에서는 고칠 수 없습니다. |
| 시계 시각이 한 시간 다름 | 빌드한 PC와 다른 시간대에 살거나, UTC 차이를 직접 넣었거나(서머타임 없음), 그 시간대의 서머타임 규칙이 빌드 뒤에 바뀌었습니다(해마다 규칙이 바뀌는 시간대도 있음). 인스펙터 **시각**을 확인하고 다시 빌드·업로드하세요. |
| 시계를 넣었더니 퍼포먼스 랭크가 내려감 | 먼저 Light 2개(손전등·깊이 라이트)를 보세요. 필요 없는 쪽을 **넣을 기능**에서 끄세요. |
| SDK에 파라미터가 256비트를 넘는다고 나옴 | 시계는 동기화 파라미터를 8비트(웨이포인트를 빼면 4비트) 씁니다. 다른 기믹의 파라미터를 줄이거나 동기화를 꺼서 비우세요. |

## 업데이트·제거

- **업데이트:** 새 패키지를 위에 덮어 임포트합니다(모두 체크한 채 Import). 설정은 씬의 `PulseWatch` 오브젝트에 저장돼 있어서 그대로 남습니다. `Assets/Pyrite9/PulseWatch/` 안의 파일(프리팹·셰이더·텍스처)은 고치지 마세요 — 업데이트로 덮어써집니다.
- **아바타에서 빼기:** 아바타의 `PulseWatch` 오브젝트를 지웁니다(Hierarchy에서 꺼 둔 시계도 빌드에서 빠집니다).
- **프로젝트에서 지우기:** 먼저 아바타에서 시계를 빼고, 그다음 `Assets/Pyrite9/PulseWatch/` 폴더를 지웁니다. 아바타의 `PulseWatch` 오브젝트에 "Missing (Mono Script)"가 보이면 그 오브젝트를 지우세요(Missing Script가 있으면 SDK가 업로드하지 않습니다).
- 인스펙터의 변경 기록은 이 README에서 읽어 옵니다 — README 파일은 패키지 폴더에 그대로 두세요.

## 참고

- 휴머노이드 아바타만. 시계는 아바타에 하나.
- FX 레이어를 최대 15개 씁니다(모든 기능 켬, 디버그 막대 끔). 레이어는 아바타의 Write Defaults 설정에 맞춰집니다(Modular Avatar "Match Avatar Write Defaults").
- Action·Base·Additive·Gesture 레이어는 쓰지 않아 GoGo Loco·이모트와 같이 쓸 수 있습니다. 손가락 자세(GestureLeft·GestureRight)는 읽기만 합니다.
- 손목 감지는 각도를 Contact 거리로 바꿔 재므로 착용자 화면에서만 돌고, 남에게는 결과(열림)만 동기화됩니다.
- 손전등은 그림자를 드리우지 않습니다. 깊이 라이트는 스캔 파동 1.4초 동안만 켜집니다.
- Unity 에디터에서 Pulse Watch 인스펙터를 열면 하루 한 번 GitHub(`api.github.com`)에 이 패키지의 최신 버전을 묻습니다. 개인 정보는 보내지 않고, 버전 글자를 누르면 바로 다시 확인합니다.
- 퍼포먼스(모든 기능 켬, 디버그 막대 끔, 대략): 동기화 8비트, FX 레이어 15, Contact 수신 126 + 송신 2(전부 Local Only), VRC Constraint 18, VRC Raycast 2, Light 2(둘 다 착용자 쪽에서만 켜짐), 렌더러 25(스킨 3)·머티리얼 21, 메시 14·삼각형 약 2,400, GrabPass 2, PhysBone 0, 텍스처 글자 1024×768·이름표 1장·메뉴 아이콘 13장(256×256, 디버그 막대를 넣으면 14장). 닫혀 있는 동안 시계 렌더러는 꺼지지만 집계에는 들어갑니다.
- 시계 숫자·글자 텍스처는 Noto Sans KR(SIL Open Font License 1.1)로 렌더한 비트맵입니다. 글꼴 파일은 들어 있지 않습니다. 이름표 글자는 빌드할 때 이 PC의 글꼴로 그립니다.
