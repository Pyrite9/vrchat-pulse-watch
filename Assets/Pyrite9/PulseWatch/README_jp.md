# Pyrite9 Pulse Watch

バージョン 0.1.2（2026-11-01）

VRChat アバター用のポップアップ式腕時計ギミックです。ヒューマノイドのアバターにプレハブを入れるだけで、ビルド時にそのアバターの前腕に時計を合わせます。
時計を見るように手首を目に向けると、手首の上にホログラムが開きます — 着用者の時刻、周りの人を映すレーダー、スキャンの波、指で押すウェイポイント・ライトのボタン。手首を目から離すとたたまれます。

English: `README_en.md` / 한국어: `README_ko.md` / 利用規約: `LICENSE.txt`

## 機能

- 手首を目に向けると時計の上にホログラムが開く — 時刻・日付・レーダー。デスクトップではメニューの **開いたままにする**
- レーダー：周囲 14 m までの人を 12 方向 × 距離 5 段階の格子で表示、埋まったマスの数も出る — 自分にだけ見える
- 開くとスキャンの波が目から 14 m まで床・壁・人の上を走る — 深度ライトでどのワールドでも（自分にだけ見える）
- ウェイポイント：反対の手を指差しの形にして時計の下のボタンを押すとレーザーが出て、その手のトリガーで床・壁・天井に印を置ける — 自分だけ見るか、他の人にも見せるかを選べる。印の上に名札、円盤に方向と距離
- ライト：もう一つのボタンで時計から視線の方へスポットライトを照らす — 自分にだけ見える
- 円盤の輪に方位、時計にこのワールドの滞在時間
- 時計は自分のタイムゾーンの時刻とワールド座標を他の人にも表示し、フレームレートは自分にだけ表示
- 話している間は円盤の外側の輪が光り、ミュート中は赤く点滅してマイクの印が出る
- 左右の手首、手首の外側・内側を選べ（どちらもメニューで切り替え）、ホログラムを他の人に隠すこともできる
- ホログラムの後ろはすりガラス、横から見ると光が手首まで流れ落ちる — どちらも画面をコピーしない
- アバターが最初に見えたときに時計のシェーダーを温めておくため、初めて開くときに止まらない
- ビルド時にアバターの前腕に合わせる。アクセント色・ウェイポイント色を選べ、機能ごとに外せる（外した機能はビルドに入らない）

## 必要なもの

- Unity 2022.3（VRChat）
- VRChat SDK – Avatars 3.10 以降
- Modular Avatar
- NDMF（Non-Destructive Modular Framework）

lilToon は不要です（時計は専用のシェーダーを使います）。

動作確認環境：Unity 2022.3.22f1、VRChat SDK Avatars 3.10.5、Modular Avatar 1.18.7、NDMF 1.14.8。
これより古いバージョンやプレビュー版（alpha・beta）では動作を確認していません。

- **PC 専用です。** 同じアバターの Android / Quest 版もアップロードする場合は、Android 向けにビルドする前に `PulseWatch` オブジェクトを削除するか、オフにしてください。
- すべての機能をオンにすると、アバターに Light が 2 つ（ライト・深度ライト）加わり、スキャンの波とウェイポイントのレーザーのためにアバターの Bounds が大きく広がります。不要な機能は **入れる機能** で外せます（「誰に見えるか・コスト」「パフォーマンス」参照）。

## 導入

1. **必要なパッケージを導入します。** VCC / ALCOM でアバタープロジェクトを「管理」（Manage Project）で開き、**Modular Avatar** を追加します。
   NDMF は Modular Avatar と一緒に自動で導入されます。安定版（プレビュー版ではないもの）を使ってください。
   - 一覧にない場合は、先に Modular Avatar 公式サイトの「Add to VCC」でリポジトリを追加してください。
2. **このパッケージをインポートします。** `.unitypackage` をダブルクリック（または Unity の `Assets > Import Package > Custom Package…`）し、すべてチェックしたまま **Import** を押します。ファイルは `Assets/Pyrite9/PulseWatch/` に入ります。

## 使い方

1. Project ウィンドウで `Assets/Pyrite9/PulseWatch/` を開き、`PulseWatch.prefab` を Hierarchy のアバター（VRC Avatar Descriptor が付いたオブジェクト）にドラッグします。アバターの子オブジェクトになります。
   - **アバターの直下（ルートの子）に置いてください。** ボーン（Hips など）の下に置くと、デスクトップ時の足元の印とスキャンの床がそのボーンの高さに浮いてしまいます。**アバターの外（シーン直下など）に置くと動作しません。**
   - プレハブを Unpack しないでください（アップデートが反映されません）。
2. Hierarchy で `PulseWatch` を選ぶとインスペクターが表示されます。最初の区画（基本）の **Menu language**（`EN` / `日本語` / `한국어`）で **日本語** を選ぶと、ゲーム内メニュー・インスペクター・時計の日付（`10.29 (木)`）が日本語になります（既定は EN — 日付は `THU 10.29`）。
3. （任意）他の設定を変更します（下の「設定」参照）。最初に着ける手首、色、入れる機能など。
4. 動作を試します：
   - Unity で **Play** を押すと時計がビルドされ、インスペクターの **最後のビルド** に結果が入ります（Play を止めた後に表示）。Play モードでは手首の検出とメニューは動作しないため、VRChat で確認してください。
   - `VRChat SDK > Show Control Panel > Builder` → **Build & Test** を実行したら、VRChat でテストアバターに着替えます。VR では時計を着けた手首を目に向けてみてください。デスクトップでは **Pulse Watch** メニューの **開いたままにする** をオンにします。
   - 問題なければ **Build & Publish** します。Build & Test で確認できるのは自分の画面だけです — 他の人からの見え方は（Private で）アップロードした後に確認できます。
5. 結果を確認します。正しく合わせられた場合、**最後のビルド** にアバター名・ビルド時刻・手首・大きさと **警告：なし** が表示されます。
   - 「アバターの中（VRC Avatar Descriptor のオブジェクトの下）に入れてください。」と出たら、時計がアバターの外にあります。ビルドしても「まだビルドの記録がありません」のままなら、ビルド処理が時計まで届いていません（Console に赤いコンパイルエラーがないか、時計のオブジェクトがオフになっていないか確認してください）。
   - 警告は Console（`Window > General > Console`）にも `[Pyrite9 Pulse Watch] WARN` で始まる黄色い行で表示されます — 「困ったとき」を見てください。詳しい内容はプロジェクトフォルダーの `Logs/Pyrite9_PulseWatch_build.txt` に記録されます。

ビルド時にアバターの前腕・手・頭を測り、時計の位置と大きさ（前腕の長さに比例）、手の甲の向き、目の位置、レーザーが出る人差し指の先を合わせます。シーンは変更されません — 変わるのはビルド用のコピーだけです。

## Expression Menu

メインメニューにサブメニュー **Pulse Watch** が一つ追加されます（項目名は **メニュー言語** に従いますが、`Pulse Watch` という名前はそのままです）：

| 項目 | 種類 | パラメーター | 動作 | 他の人の画面 |
|---|---|---|---|---|
| 開いたままにする | トグル | `PulseWatch/Manual` | 手首の検出に関係なくホログラムを開いたままにする。デスクトップではこれで開く | ローカル — 開いた結果（`Open`）は同期され、他の人の画面でも開く |
| ウェイポイント ▸ 置く | ボタン | `PulseWatch/WpTap` | VR：レーザーをオン（時計のボタンを押すのと同じ）。デスクトップ：足元に印 | ローカル — レーザー・印は同期（他の人に見えるのは `他の人に見せる` のとき） |
| ウェイポイント ▸ 消す | ボタン | `PulseWatch/WpClear` | 印を消す | ローカル — 消した結果は同期 |
| ウェイポイント ▸ 他の人に見せる | トグル（保存） | `PulseWatch/WpShow` | オン：他の人にも印・名札・レーザー・円盤の方向が見える | 同期 |
| ライト | トグル | `PulseWatch/Flash` | ライトをオン（時計のタブを押すのと同じ） | ローカル — 他の人には見えない |
| 他の人に隠す | トグル（保存） | `PulseWatch/Hide` | オン：他の人の画面では時計が開かない（自分の画面ではそのまま）。ウェイポイントはこれではなく `他の人に見せる` で決まる | 同期 |
| 設定 ▸ 感度：広く / 狭く | トグル（保存） | `PulseWatch/Sens` | 開く・閉じる 4 つの角度を +10° / −10°。両方オフで通常 | ローカル — 検出は着用者の側でだけ |
| 設定 ▸ 右手に着ける | トグル（保存） | `PulseWatch/Right` | 右の手首へ（既定はインスペクターの **着ける手首**） | 同期 |
| 設定 ▸ 手首の内側に着ける | トグル（保存） | `PulseWatch/Inside` | 手のひら側（タクティカル式）へ — そのときは手のひらを目に向けて見る | 同期 |
| 設定 ▸ デバッグメーター | トグル（保存） | `PulseWatch/Debug` | インスペクターで **デバッグメーター** をオンにしたときだけ表示。検出角度の調整用。最初はオン（バーが表示される） | ローカル — 他の人には見えない |

ライトの項目はライト機能を外すと、ウェイポイントのサブメニューはウェイポイント機能を外すと表示されません。

同期パラメーター：**8 ビット**（`Open`・`Right`・`Hide`・`Inside`・`WpOn`・`WpSeq`・`WpLaser`・`WpShow`、すべて `PulseWatch/` の下。ウェイポイントを外すと 4 ビット）。アバター全体の上限は 256 ビットで、超えると SDK がアップロードを止めます。
保存されるもの：感度・右手・手首の内側・他の人に隠す・他の人に見せる・デバッグメーター — アバターを読み込み直しても残ります。開いたままにする・ライト・印は保存されません。

## ゲーム内での動き

| | VR | デスクトップ |
|---|---|---|
| 開く | 時計を着けた手首を、時計を見るように目に向ける（文字盤が目の方へ 40° 以内 + 時計が視界の中心から 45° 以内を 0.15 秒保つ）。目から離すと（55°・60° を超えると）たたまれる | メニュー `開いたままにする` |
| ウェイポイントのレーザー | 時計のない手を **指差しの形（人差し指だけ伸ばした手）** にして、その人差し指で時計の板の下のタブを押し込んで離す → その手からレーザー | なし |
| 印を置く | レーザーを向けてその手の **トリガー** — 当たった所（床・壁・天井、50 m まで）に印 | メニュー `ウェイポイント ▸ 置く` — 足元 |
| 印を消す | タブを 1.2 秒押し続ける（2 秒以内にもう一度押すと取り消し） | メニュー `ウェイポイント ▸ 消す` |
| ライト | 同じ形でウェイポイントのタブの隣のタブを押す（もう一度押すとオフ） | メニュー `ライト` |
| 手首を替える | メニュー `設定 ▸ 右手に着ける`・`手首の内側に着ける` | 同じ |

- 印は宙に浮かぶひし形と名札で、壁越しにも見えます。円盤には印の方向と距離が表示されます。印は一つだけで、置き直すとそこへ移動します。
- スキャンの波は開くたびに出て（5 秒以内に開き直したときは出ません）、1.4 秒で目から 14 m まで広がります。
- タブは指差しの形のときだけ押せるようになります — 開いた手や握った手で触れても反応しません。この手の形に表情を割り当てているアバターでは、押すときに表情も変わることがあります（アバターの FX のジェスチャー表情）。
- 時計のタイムゾーンはビルドした PC のもの（またはインスペクターで指定した UTC との差）で、他の人もあなたの時計で同じ着用者の時刻を見ます。**この PC のタイムゾーン** がオンなら、そのタイムゾーンの夏時間の規則（ビルドした年のもの）も焼き込まれ、日付に合わせて自動で切り替わります。UTC との差を直接入力した場合は、夏時間なしで固定されます。

## 誰に見えるか・コスト

機能ごとに、着用者（自分）と他の人の画面に見えるもの、その機能がアバターに加えるものです。コストは、Lapwing に時計を入れてその機能だけをオフにしてビルドしたときに、VRChat SDK のパフォーマンス統計（PC）で減った値です。いくつかの部品は 2 つの機能で共用しているため、合計は下の「パフォーマンス」の全体の値と必ずしも一致しません。

| 機能 | 自分 | 他の人 | コスト |
|---|---|---|---|
| 基本（常に入る）— ホログラムの開閉、時刻・日付 | 見える | 一緒に開く（`他の人に隠す` なら開かない）、同じ着用者の時刻 | 同期 4 ビット、FX レイヤー 3、コンタクト 4（Local Only）、レンダラー 6、マテリアルスロット 6、ポリゴン 22、VRC Constraint 10、テクスチャメモリ 1.00 MB（文字アトラス） |
| プリウォーム（常に入る）— アバターが最初に見えたときに時計のシェーダーを 1 回ずつ描き、自分で消える | 見えない（胸の中の 0.1 mm の三角形） | 他の人の PC でも同じ — その人が初めて時計を見るときも止まらない | レンダラー 1、Animator 1（Cull Completely）、ビルドに入る時計のシェーダー 1 つにつきマテリアルスロット 1・ポリゴン 1（すべてオンで 5、すべて外すと 1） |
| レーダー | マス・人数 | 見えない（空の円盤） | コンタクト受信 120（Local Only）、FX パラメーター 121 |
| スキャン | 開くときの波 | 見えない | ポリゴン 4,610、レンダラー 3、マテリアルスロット 3、VRC Constraint 2、FX レイヤー 1、Bounds 30 × 31 × 30 m（14 m の波） |
| └ 深度ライト | 波の間だけ点く（何も照らさない） | 点かない | Light 1（Directional） |
| ウェイポイント | ボタン・レーザー・照準・印・名札・円盤の方向 | ボタンのタブだけ。レーザー・印・名札・方向は `他の人に見せる` がオンのときだけ | 同期 4 ビット、FX レイヤー 5、VRC Raycast 2、コンタクト 2（Local Only）、レンダラー 8（スキン 1）、マテリアルスロット 8、ポリゴン 28、VRC Constraint 3、Bounds 67 × 53 × 18 m（50 m のレーザー） |
| └ 名札 | 印の上 | ウェイポイントと同じ | レンダラー 1、マテリアルスロット 1、ポリゴン 2、テクスチャメモリ 0.05 MB |
| ライト | 光・点いたタブ | 見えない | Light 1（Spot）、FX レイヤー 2、コンタクト 2（Local Only）、レンダラー 3、マテリアルスロット 3、ポリゴン 18、VRC Constraint 1 |
| 声のリング | 話すと光る・ミュート中は赤 | 見える（点滅のタイミングは人ごとに違う） | FX レイヤー 2 |
| FPS | 見える | 見えない | なし（シェーダーで描画） |
| 座標 | 見える | 見える | なし（シェーダーで描画） |
| 方位 | 見える | 見える | レンダラー 1（スキン）、マテリアルスロット 1、ポリゴン 2 |
| 滞在時間 | 見える | 見えない | FX レイヤー 1 |
| すりガラス | 見える | 見える | レンダラー 4、マテリアルスロット 4、ポリゴン 8 |
| 光のにじみ | 見える | 見える | レンダラー 1、マテリアルスロット 2（うち 1 つは円盤の 2 つ目のスロット）、ポリゴン 4、テクスチャメモリ 0.45 MB（ビルド時に焼いたこの時計の絵 2 枚） |
| デバッグメーター（初期値オフ） | メニューでオンにしたとき | 見えない | FX レイヤー 1、レンダラー 1、マテリアルスロット 1、ポリゴン 2 |

- **着用者の PC でだけ動くもの：** 手首の検出、レーダー、ボタンの押し込み（コンタクト 128 個はすべて Local Only）、スキャンの波・深度ライト、ライト。他の人の PC では動きません。
- **他の人の PC でも動くもの：** 同期パラメーター、FX レイヤー（アニメーター）、VRC Constraint、ホログラムが開いている間のすりガラス・光のにじみ（見る人の GPU — 画面コピーなし）、プリウォーム（その人の画面にアバターが最初に入ったときに 1 回）、ウェイポイントのレーザーがオンの間の VRC Raycast（他の人の画面でもそれぞれ印の位置を計算 — `他の人に見せる` がオフでも動く）。
- 時計を閉じている間は時計のレンダラーはオフですが、パフォーマンス統計はビルドに入っているものを数えます — Light も着用者の側で点く前から 2 つと数えられます。
- 他の人の画面では、それぞれの画面にあるあなたのアバターのコピーがレーザーを撃って印を置くため、位置がわずかにずれることがあります。後から来た人には、次に置くまで印が見えません。
- メニュー言語・色・位置・検出角度はビルド時にアバターに焼き込まれます。

## パフォーマンス

すべての機能オン（初期値、デバッグメーターオフ）。Lapwing に時計を入れたときと外したときの、VRChat SDK のパフォーマンス統計（PC）の差です（0.1.1、VRChat SDK 3.10.5）。

| 項目 | 時計が加える値 |
|---|---|
| Polygons | 4,693（うちスキャンの波 4,610） |
| Bounds | アバターの大きさ（Lapwing 1.00 × 1.65 × 0.60 m）→ **66.83 × 59.84 × 30.00 m** — ウェイポイントのレーザーとスキャンの波。両方外すとほぼアバターの大きさのまま（胸のプリウォームの 0.6 m の箱で数 cm 増えることがある） |
| Skinned Meshes / Meshes | 2 / 23 |
| Material Slots | 30（うちプリウォーム 5） |
| Bones | 1 |
| Lights | **2**（ライト・深度ライト — どちらも着用者の側でだけ点く） |
| Contacts | 0（コンタクト 128 個 — 受信 126・送信 2 — はすべて Local Only で、この項目には入らない） |
| Constraints / Constraint Depth | 18 / 18（すべて VRC Constraint） |
| Raycasts | 2 |
| Texture Memory | 1.50 MB（うち 0.45 MB は光のにじみの焼いた絵） |
| Animators | 1（プリウォームのもの、Cull Completely — 誰にも見えていない間は止まる） |
| PhysBones · Particle Systems · Trail / Line Renderers · Cloths · Physics Colliders / Rigidbodies · Audio Sources | 0 |
| 同期パラメーター | 8 ビット（256 ビット中） |
| FX レイヤー / FX パラメーター | 15 / 151（同期しない内部の値を含む、ほとんどがレーダーのマス） |
| GrabPass | 0 |

- メニューアイコン 13 枚（256×256、デバッグメーターありで 14 枚）は Expression Menu でだけ使うため、Texture Memory には入りません。

## 設定（Pulse Watch コンポーネント）

メニュー言語を日本語にしたときにインスペクターに表示される名前です。ゲージはダブルクリックで既定値に戻ります。

| 区画 | 項目 | 意味 |
|---|---|---|
| 基本 | メニュー言語 | `EN` / `日本語` / `한국어` — メニューの表示と時計の日付（`THU 10.29` / `10.29 (木)` / `10.29 (목)`、ビルド時に反映）とインスペクターの言語。既定は EN |
| | 着ける手首 | 左手（既定）/ 右手 — 最初に着ける手首。メニューの **設定 ▸ 右手に着ける** でプレイ中も切り替えられる（保存される） |
| | アクセント色 | ホログラムのアクセント（針・ゲージ・強調）とスキャンの波。既定は黄色 #FFE00D、**既定** ボタンで戻す |
| | ウェイポイント色 | ウェイポイントのレーザー・印・名札・照準、円盤の矢印とウェイポイントボタン。既定は水色 #4CD9FF。ホログラムは暗いガラスの上の光なので **暗い色はかすれて見えます**（インスペクターが警告） |
| 入れる機能 | レーダー | 14 m 以内の人 — Local Only コンタクト 120 |
| | スキャン | 開くときの波 — FX レイヤー 1 |

| | ウェイポイント | ボタン・レーザー・印 — 同期 4 bit、VRC Raycast 2、FX レイヤー 5 |

| | ライト | タブとスポットライト — 本物の Light 1 つ、FX レイヤー 2 |
| | 声のリング | 話すと光る・ミュートで赤 — FX レイヤー 2 |
| | FPS | 時計にフレームレート（自分の画面だけ） |
| | 座標 | 日付の横に時計のワールド座標（X Y Z、0.1 m） |
| | 方位 | 円盤の輪に北（ワールドの +Z） |
| | 滞在時間 | このワールドにいる時間（アバターの読み込みから、自分の画面だけ） — FX レイヤー 1 |
| | すりガラス | 円盤と時計の後ろに、周りがぼんやり映る（ワールドのリフレクションプローブをぼかしたもの）煙ったガラス。画面コピーなし |

| | 文字盤の高さ | 前腕の軸から文字盤までの高さ（0.03〜0.2、既定 0.09）。厚い袖に埋まるなら上げる |
| 検出（°） | 文字盤 — 開く / 閉じる | 文字盤が目の方へこの角度以内なら開き（既定 40）、閉じる角度を超えると閉じる（既定 55） |
| | 視線 — 開く / 閉じる | 時計が視界の中心近く（頭の正面と時計の方向）にこの角度以内なら開き（既定 45）、閉じる角度を超えると閉じる（既定 60） |
| | 待ち時間（秒） | 両方の条件がこの時間続くと開く（0〜1、既定 0.15） |
| | デバッグメーター | オン：メニューに **設定 ▸ デバッグメーター** が増え、前腕の上のバーが文字盤・視線の近さと開く・閉じる位置を表示（自分にだけ）。角度を合わせたらオフに |

- 位置の値は前腕の長さに対する割合なので、アバターの大きさに関係なく使えます。
- 検出の「閉じる」は「開く」より大きくしてください — そうしないと時計が点滅します（インスペクターが警告します）。
- オフにした機能はビルドに入りません — オブジェクト・コンタクト・レイヤー・パラメーターなし。字下げした項目（└）は上の項目がオフだと薄く表示され、一緒に外れます。

インスペクターには他に次の項目があります（表示はメニュー言語に従います）：

- **バージョン**：1 日 1 回 GitHub に最新版を問い合わせ、新しいバージョンがあればお知らせします（下の「補足」）。
- **最後のビルド**：最後の Play・Build & Test・アップロードのアバター・時刻・手首・大きさ・時計のタイムゾーン・機能数・同期ビット・FX レイヤー数・コンタクト数・警告。ビルドログとこの README を開くボタンがあります。**確認** を押すと、確認した警告をそのアバターではたたみます。
- **更新履歴**：この版の変更内容（この README から読み込み）。

## 困ったとき

Console の警告は英語で表示されます。インスペクターの **最後のビルド** にも同じ英文が表示されます。

| Console のメッセージ（`[Pyrite9 Pulse Watch] WARN …`）または症状 | 対処 |
|---|---|
| インポート直後に `error CS0246: The type or namespace name 'nadena' could not be found` などの赤いエラーが出て、Play・ビルドができない | Modular Avatar（と NDMF）が導入されていません。VCC / ALCOM で Modular Avatar を追加すると、Unity が再コンパイルした後にエラーが消えます。 |
| `not a humanoid avatar — watch not built` | ヒューマノイドのアバター（Rig: Humanoid、ルートに VRC Avatar Descriptor）だけに対応しています。 |
| `head bone missing — watch not built`、`lower arm / hand bone missing — watch not built` | アバターのヒューマノイドのボーン割り当て（頭・前腕・手）を確認してください。 |
| `L/R: index / little finger bones missing — back of the hand assumed …`、`L/R: back of the hand undefined — using up` | 指のボーンがないため手の甲の向きを推定しました。時計が手首の横や内側に付いて見える場合は、指のボーン割り当てを確認してください。 |
| `L/R: index finger bones missing — the laser starts … past the hand` | 人差し指のボーンがないため、レーザーが手の前から出ます。動作はします。 |
| `name tag: no font has "…" — left out of the tag` | 名前の中の該当する文字を描けるフォントがこの PC にないため、その文字を外して焼き込みました。別の名前にするか、その文字を外してください。 |
| `the watch is under the armature (…) — put it right under the avatar root …` | プレハブがボーンの下にあります。ビルドはされますが、デスクトップの足元の印とスキャンの床がそのボーンの高さに浮きます。アバターのルート直下にドラッグしてください。 |
| `… out of range — … used` | インスペクターの数値が範囲外だったため（手入力やスクリプト）、一番近い範囲内の値で作りました。その設定を確認してください。 |
| `… Pulse Watches on one avatar — only the first is built` | 時計は 1 アバターにつき一つだけです。余分なものを削除してください。 |
| `shader … not found`、`glyph atlas missing …`、`… menu icons missing …`、`VRC… not found` | パッケージのファイルが欠けているか、SDK が古すぎます。パッケージをインポートし直し、だめなら VRChat SDK を更新してください。 |
| `Build error: …`（最後のビルド）、Console に赤いエラー | 時計は組み込まれていません（アバターの他の部分はビルドされます）。赤いエラーと `Logs/Pyrite9_PulseWatch_build.txt` を送ってください（「お問い合わせ」）。 |
| Pulse Watch メニューが出ない | プレハブがアバターの外にあるか、時計のオブジェクトがオフになっているか、「— not built」の警告でビルドが止まっています（上の表）。直した後にビルド・アップロードし直してください。 |
| メニュー・日付が英語で出る | インスペクターの **Menu language** を **日本語** にしてビルドし直してください。 |
| VR で手首を見ても開かない / 開きやすすぎる | メニューの **設定 ▸ 感度：広く**（開かないとき）・**狭く**（開きやすすぎるとき）を使ってください。さらに細かく合わせるには、インスペクターの **検出** の角度を変え、**デバッグメーター** をオンにして VR でバーを見ながら合わせてください。手首の内側に着けているなら、手のひらを目に向けると開きます。 |
| デスクトップで開かない | デスクトップでは手首の検出が動きません。メニューの **開いたままにする** をオンにしてください。 |
| 文字盤が袖に埋まる | Pulse Watch オブジェクトを選ぶとシーンビューの手首に円盤の位置が表示されます — どの向きから見ても赤なら袖の中です。インスペクターの **位置 ▸ 文字盤の高さ** を上げてください（円盤がすぐ動きます）。 |
| タブを押しても反応しない | 時計の **ない** 手を指差しの形（人差し指だけ伸ばした手）にして、その指先でタブを押し込んで離してください。開いた手や握った手では押せません。 |
| レーザーは出たが印が置かれない | レーザーを出している手のトリガーを引いてください。50 m 以内に当たる面が必要です。レーザーは 10 秒撃たないと自動で消えます。 |
| レーダーに誰も出ない | レーダーは他の人の頭のコンタクトを拾います。14 m 以内に人がいる必要があります。他の人の画面では仕様上、空の円盤です。 |
| スキャンの波が床・壁に沿わず輪だけ出る | **深度ライト** がオフだと、深度テクスチャのないワールドでは輪と床の格子だけになります。鏡や平行投影のカメラでは表面のスキャンは出ません。 |
| 特定のワールドでだけ、ライトが非常に速く点滅する（立ち止まっていても） | そのワールドのリアルタイムライトが、Unity が一つのオブジェクトに当てられる数より多く、ワールドのライトも変化し続けるため、Unity が毎フレーム選ぶライトにこの時計のライトが入ったり外れたりしています。ワールド側のライト数の上限によるもので、アバター側では直せません。 |
| 時計の時刻が 1 時間ずれる | ビルドした PC と違うタイムゾーンに住んでいるか、UTC との差を直接入力したか（夏時間なし）、そのタイムゾーンの夏時間の規則がビルド後に変わった可能性があります（毎年規則が変わるタイムゾーンもあります）。インスペクターの **時刻** を確認して、ビルド・アップロードし直してください。 |
| 時計を入れたらパフォーマンスランクが下がった | Light 2 つ（ライト・深度ライト）と Bounds（ウェイポイントのレーザー・スキャンの波）を確認してください（「パフォーマンス」）。Light は不要な方を **入れる機能** でオフにすると 1 つずつ減り、Bounds はウェイポイントとスキャンを両方オフにするとアバターの大きさに戻ります。 |
| SDK にパラメーターが 256 ビットを超えると出る | 時計は同期パラメーターを 8 ビット（ウェイポイントを外すと 4 ビット）使います。他のギミックのパラメーターを減らすか、同期をオフにして空きを作ってください。 |

## 更新・削除

- **更新：** 新しいパッケージを上書きでインポートします（すべてチェックしたまま Import）。設定はシーンの `PulseWatch` オブジェクトに保存されているので、そのまま残ります。`Assets/Pyrite9/PulseWatch/` の中のファイル（プレハブ・シェーダー・テクスチャ）は変更しないでください — 更新で上書きされます。
- **アバターから外す：** アバターの `PulseWatch` オブジェクトを削除します（Hierarchy でオフにした時計もビルドから外れます）。
- **プロジェクトから削除：** 先にアバターから時計を外し、その後 `Assets/Pyrite9/PulseWatch/` フォルダーを削除します。アバターの `PulseWatch` オブジェクトに「Missing (Mono Script)」が出ていたら、そのオブジェクトを削除してください（Missing Script があると SDK はアップロードしません）。
- インスペクターの更新履歴はこの README から読み込みます — README ファイルはパッケージフォルダーにそのまま置いてください。

## 補足

- ヒューマノイドのアバターのみ対応。時計は 1 アバターにつき一つまで。
- FX レイヤーを最大 15 使います（すべての機能オン、デバッグメーターオフ）。レイヤーはアバターの Write Defaults 設定に合わせられます（Modular Avatar「Match Avatar Write Defaults」）。
- Action・Base・Additive・Gesture レイヤーは使わないので、GoGo Loco やエモートと一緒に使えます。手のジェスチャー（GestureLeft・GestureRight）は読み取るだけです。
- 手首の検出は角度をコンタクトの距離に変えて測るので、着用者の側だけで動作し、他の人には結果（開いているか）だけが同期されます。
- ライトは影を落としません。深度ライトはスキャンの波の 1.4 秒の間だけ点きます。
- Unity エディターで Pulse Watch のインスペクターを開くと、1 日 1 回 GitHub（`api.github.com`）にこのパッケージの最新版を問い合わせます。個人の情報は送信しません。バージョンの文字を押すとすぐにもう一度確認します。
- パフォーマンスの数値は「パフォーマンス」、機能ごとのコストは「誰に見えるか・コスト」をご覧ください。
- 時計の数字・文字のテクスチャは Noto Sans KR（SIL Open Font License 1.1）でレンダリングしたビットマップです。フォントファイルは同梱していません。名札の文字はビルド時にこの PC のフォントで描きます。
