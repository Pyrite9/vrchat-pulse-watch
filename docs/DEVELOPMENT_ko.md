VRChat 아바타용 무료 기믹 **Pyrite9 Pulse Watch** v0.1.0을 만들며 푼 기술 과제·버린 안·겪은 함정 정리. 사용법은 [README](../Assets/Pyrite9/PulseWatch/README_ko.md) 참고.

## 만든 방식

- **역할**
  - 제작자: 방향 결정, VR 인게임 판정
  - Claude Code: 구현, 후보 렌더, 측정, 문서화 — MCP for Unity로 에디터 직접 조작
  - 화면 클릭보다 에디터 안 코드 실행과 Unity batchmode 위주
- **한 바퀴**: 명세 초안과 질문 → 후보 2~5개 렌더(비교판·GIF) → 제작자가 고름 → 결정 번호로 확정 → 구현 → 에디터 검증 → Build & Test 3/3 → 시험 업로드 → VR 판정
  - 빠를 때는 한 시간에 2~3바퀴
- **결정은 지우지 않음**
  - 뒤집힌 결정도 "폐기"로 남김 — 무엇을 왜 버렸는지 나중에 따라갈 수 있게
  - 개발 문서 하나를 정본으로, 작업 기록은 시간순으로 이어 씀
- **정지 화면 통과 ≠ 해결**
  - 에디터 렌더는 통과, 인게임에서 실패한 일 네 번(판 위치, 14 m 밖 탐지, 스캔 어둠, 버튼 앞 감지 구)
  - 그래서 최종 판정은 항상 VR 인게임
- **시험 행렬**
  - 체형이 다른 아바타 3종을 한 씬에 나란히 배치: Lapwing 팔뚝 0.196 m, Milfy 0.177 m, Kipfel 0.135 m(Kipfel은 루트 scale 1.12)
  - 메뉴 언어와 색 조합도 셋 다르게 넣어 한 번에 확인
- **검수**
  - 공개 전 읽기 전용 리뷰 두 차례
    - 코드·셰이더·인스펙터·배포
    - 코드 대조·문서 일관성·일영한 문장
  - 지적은 원본 코드에서 다시 확인한 뒤 수정

## 기술 과제와 해법

### 1. 손목을 보는지 알아내기 — 각도를 Contact 거리로

- **문제**: 아바타는 Udon처럼 손의 회전을 직접 읽을 수 없음
- **해법**
  - 시계 면 법선 끝에 Local Only Proximity 수신기, 눈을 겨누는 VRC Aim Constraint 끝에 송신기
  - 두 끝의 거리 `2L·sin(θ/2)`가 각도 θ를 나타냄
  - 판정은 두 쌍
    - **face**: 시계 면 법선 ↔ 눈 방향
    - **gaze**: 머리 정면 ↔ 시계 방향
- **수치(문턱)**
  - 처음: face 30/45°, gaze 35/50°
  - VR 체감 뒤 10° 넓혀 확정: **열림 40°/닫힘 55°, 45°/60°**
  - 열림·닫힘을 다르게 둬 경계에서 깜빡임 없음
  - 0.15초 머물러야 열림
- **손 비틀림**
  - 아래팔 본은 손을 돌리는 회전을 일부만 받음
  - Aim Constraint의 Up을 손등 기준점으로 잡아 손 비틀림을 그대로 따라감
- **동기화**
  - 판정은 착용자 사본에서만
  - 남에게는 결과 `Open` 1비트만 전송

### 2. 아무 아바타의 팔뚝에 맞추기 — NDMF 빌드 플러그인

- Humanoid의 LowerArm·Hand 본으로 팔뚝 축과 손등 방향 계산
- **수치**
  - 시계 위치: 축의 0.88 지점
  - 크기: `팔뚝 길이 / 0.25 m`
  - 원판 지름: Lapwing 75 mm, Milfy 67 mm, Kipfel 51 mm
- **착용 자리 4곳**: 양 손목의 손등 쪽·손바닥 쪽 모두 생성
  - Parent Constraint 소스를 FX가 골라 왼손·오른손·안쪽을 메뉴에서 바로 전환
- 인스펙터에서 끈 기능은 **빌드에 아예 안 들어감** — 오브젝트, Contact, 레이어, 파라미터, 메뉴까지
- **소매에 묻혔는지 확인**: Scene 뷰 기즈모
  - 원판을 `ZTest LessEqual`(액센트 색)과 `Greater`(빨강)로 두 번 그림
  - 빨갛게 보이면 소매 안

### 3. 착용자 시각 — 동기화 0비트, 서머타임 포함

- **방식**: 모든 클라이언트가 자기 `_VRChatTimeUTCUnixSeconds`에 빌드 때 구운 시차(분)를 더함
  - 비트를 하나도 안 쓰고 모두가 같은 착용자 시각을 봄
  - 분 단위인 이유: +5:30, +5:45 지역
- **계산은 전부 uint**
  - Unix 초(약 17억)를 float로 계산하면 초 자리가 뭉개짐
  - 날짜: Hinnant `civil_from_days`
- **서머타임**
  - 버린 안: 메뉴 토글(+1비트)
  - 해법: 빌드한 PC 시간대의 올해 조정 규칙(시작·끝 월, n번째 요일 또는 고정일, 분, 이동량)을 머티리얼에 구움 → 셰이더가 날짜로 판정
  - 해를 넘기는 남반구 규칙도 처리
- **검증**
  - 셰이더 계산을 C#으로 옮겨 .NET `ConvertTimeFromUtc`와 2년 치 매시간(17,520시점) 대조
  - 한국, 이란, 미국 서부·동부, 서유럽, 영국, 호주 동부, 뉴질랜드에서 불일치 0
- **한계**: 해마다 규칙이 바뀌는 시간대(모로코)는 빌드한 해 규칙만 구워짐

### 4. 레이더 — 남의 머리를 Contact로

- **방식**: VRChat이 모든 아바타에 붙이는 내장 `Head` 송신기를 Local Only 수신기로 받음
  - 12방향 × 5링(0.4·1.5·3·5·8·14 m)
  - 칸은 세로 캡슐 — 앉거나 누운 사람도 잡힘
- **거리 한계**: Contact 모양 하나의 반경 상한 3 m → 칸 하나를 수신기 하나로 덮을 수 있는 한계가 14 m 근처
- **오탐**
  - 문제: 정면 0.6 m의 한 사람이 3칸에 잡힘
  - 해법: Proximity 값으로 바꾸고 셰이더가 옆 칸과 비교해 높은 쪽만 켬
  - 두 값의 합이 한 사람으로는 나올 수 없으면 두 명으로 판정
  - 수치: 실측 16경우에서 3칸 → 1칸, 나란히 선 두 명은 2칸
- **빈틈**
  - 문제: 원판 면적의 11.9%가 어느 수신기에도 안 닿음 — 수치 모의로 발견
  - 해법: 링별로 칸을 1·1·2·2·4조각으로 나눔
  - 수치: 수신기 60 → 120개, 놓침 8.5% → 0%
- **경로**: 수신기 값 → FX Direct BlendTree → 머티리얼 → 셰이더. 동기화 0비트
- **버린 안**: 14 m 밖을 회전하는 팔로 대략 방향만 잡는 기능
  - FX 레이어 7개, 에디터 하네스 17/18 정답
  - 인게임에서 안 보여 코드까지 삭제
  - 빌드 산출 자산 1,154 → 704로 감소

### 5. 어느 월드에서나 스캔 파동 — 보이지 않는 라이트로 깊이 강제

- **방식**: 큰 구를 `ZTest Always`로 그리고 카메라 깊이로 픽셀의 월드 위치를 되살림 → 바닥·벽·사람 위로 띠가 지나감
- **문제**: VRChat 카메라의 깊이 텍스처는 **그림자를 드리우는 Directional Light**가 있는 월드에서만 생김
  - 라이트맵으로 다 구운 월드엔 없음
- **해법**: 파동이 도는 1.4초 동안만 착용자 사본에서 Directional Light 켬
  - 세기 0.001, 그림자 강도 0, culling mask는 비어 있는 레이어 하나
  - 눈에 보이는 빛 없음 — Unity가 그림자 준비로 깊이를 먼저 그리게 만드는 역할만
- **조건 판별**: 깊이를 그대로 보여 주는 진단 셰이더로 가름
  - 세기 0 → 안 생김
  - culling mask Nothing → 안 생김
  - 빈 레이어 하나 → 생김
  - 렌더 차이 최대 1/255
- **버린 안**: 스캔 때 주변 어둡게 하기
  - linear 색공간에서 ×0.65는 화면에서 약 17%밖에 안 어두워 보임
  - 보정한 뒤에도 인게임에서 존재감 없어 제외

### 6. 웨이포인트 — 위치를 보내지 않는 동기화

- **조작**: 판 밑 탭을 반대 손 검지로 누르면 그 검지 끝에서 VRCRaycast 레이저(50 m)가 나감
  - 같은 손 트리거로 닿은 곳에 표지 고정
- **좌표를 안 보냄**
  - 레이저를 켠 동안 남의 사본도 자기 화면의 착용자 손에서 같은 레이캐스트 → 같은 곳에 표지
  - 동기화 4비트(`WpOn`·`WpSeq`·`WpLaser`·`WpShow`)
  - 늦게 들어온 사람이 엉뚱한 표지를 안 보게, 원격은 `WpSeq`가 바뀌는 걸 직접 본 뒤에만 표시
- **원판 위 방향·거리**
  - 문제: Contact로는 거리를 못 잼
  - 해법: 표지 위치를 따라가는 probe의 로컬 위치를 스킨 메시의 루트 본으로 넘김 → 셰이더가 오프셋을 m 단위로 읽음
  - 나침반도 같은 꼼수 — 남 화면에서 착용자 방위가 맞음
- **이름표**
  - 아바타는 런타임에 자기 이름을 모름 → 빌드 때 텍스처로 구움
  - OS 글꼴을 차례로 대체하며 그려 한·일·간체·번체 확인

### 7. 손가락 버튼과 오조작

- **센서**: 버튼 면 뒤에 중심을 둔 Proximity 수신기로 누른 깊이 측정
  - 0.6 이상 누름, 0.3 이하 뗌
  - 대상: 반대 손 내장 `FingerIndex`
- **1차 대책**
  - 0.1초 버텨야 누름
  - 다른 탭이 눌려 있으면 무시
  - 동작 뒤 0.2초 무시
  - 길게 눌러 지우기는 2초 되돌리기
  - 에디터 시뮬레이션은 통과, 인게임에선 뒤에서 들어온 손가락에 눌리는 문제 남음
- **버린 안**
  - 면 앞 감지 구: 인게임에서 아예 안 눌림
  - 메뉴로 만든 버튼 잠금: 이것도 제외
- **최종 해법**: 반대 손 제스처가 **FingerPoint(검지만 편 손)일 때만** 누르기 시작
  - 인게임에서 오조작 사라짐
  - 이 제스처에 표정을 붙인 아바타의 표정 충돌은 기믹이 막지 않고 README에 기재

### 8. 목소리 링 — 자기참조 AAP로 지수 smoothing

- **버린 안**: 상태 전이 크로스페이드로 잔광
  - 전이 중에도 출발 상태의 트리가 현재 입력(≈0)으로 다시 평가돼 페이드가 안 생김
- **해법**: Direct 트리에 `[1D on 자기 값]×k + [1D on 입력]×(1−k)` → `S = k·S + (1−k)·입력`
- **수치**: 올라갈 때 k = 0.7, 내려갈 때 0.955(90 fps에서 τ ≈ 0.03초 / 0.24초)
- 가중치 합이 1 → Write Defaults off에서도 정확
- **한계**: k가 프레임당 값 → fps에 따라 감쇠 속도가 달라짐
- **음소거**: 내장 `MuteSelf`로 빨갛게 깜빡임
  - 남 화면에도 보임, 비트 0

### 9. 글자 — SDF 아틀라스

- **생성**: Python으로 Noto Sans KR을 8배로 렌더 → 거리 변환 → 축소
  - 같은 입력이면 같은 파일
- **형식**: R8 한 채널, Streaming Mip
  - `tex2Dgrad`로 칸 경계 밉맵 튐 방지
- **글자 추가**: **뒤에 붙이기만**, 기존 칸이 바이트 단위로 같은지 대조
  - 22자 → 48칸(1024×768)
- 글꼴 파일은 안 넣고 OFL 고지만

### 10. 젖빛 유리와 흘러내리는 빛 — 이름 붙은 GrabPass 2개

- **블러**: 이름 붙은 GrabPass로 뒤 화면을 흐림(화면 복사는 프레임당 한 번)
- **빛 번짐**: "홀로그램을 그린 뒤 화면 − 그리기 전 화면" → **홀로그램이 더한 빛만** 골라 손목 쪽으로 끌어내림
  - 버린 안: 밝기로 거르기 — 흰 소매까지 흐름
  - 위에서 보면 사라지고 옆에서 보면 보임
- "홀로그램이 녹아 흐르는 느낌"이라는 피드백까지 목업 6번
- **함정**
  - 큰 함수를 여러 번 부르는 셰이더 → 컴파일러 시간 초과
  - 유리만 컬링되면 지난 프레임 grab과 빼져 줄무늬 → bounds 맞춤

### 11. 예산 — 동기화 8비트, FX 레이어 15

- **비트 증가**: 1 → 3 → 7 → 8
- **거절한 비트**
  - 서머타임 토글 → 규칙 굽기로 대체
  - 색 다이얼 float 2개 = 16비트 → 인스펙터 색 지정으로 대체
  - 팀 공유 4~5비트
- **0비트 원칙**: 시각, 레이더, FPS, 좌표, 나침반, 목소리, 음소거는 각 클라이언트가 같은 값을 스스로 계산하거나 내장 파라미터 사용
- **누가 비용을 내나** — 기능을 고를 때의 기준
  - 방 안 모두: 동기화, FX 레이어, Constraint, Raycast
  - 착용자만: Local Only Contact
- **FX 레이어 20 → 15**
  - 값만 옮기는 레이어 6개를 Direct 트리 하나로 묶음
  - 블렌드 트리에 Bool인 `IsLocal`을 못 씀 → 원격 분기 Driver가 로컬 float를 쓰게 해 가중치로 사용
  - 합친 뒤 90프레임 동안 같은 입력을 넣어 결과가 같은지 대조
- **Bounds도 랭크를 내림**
  - 실측: Light 2개만이 아니라 웨이포인트 레이저(50 m)와 스캔 메시(30 m) 때문에 Bounds가 1.00 × 1.65 × 0.60 → 66.83 × 59.84 × 30.00 m로 커짐
  - 컬링되지 않으려면 필요한 크기 → 그대로 두고 README에 기재
  - 기능 조합 17개와 Bounds 9개를 NDMF 처리 + SDK `CalculatePerformanceStats`로 측정 → README의 기능별 비용표 작성

### 12. 배포 — 받는 사람과 같은 파일로 시험

- **패키징**: Unity batchmode `-exportPackage`
  - 함정: 직접 다시 묶은 패키지가 임포트 0개가 됨
- **확인 항목**
  - asset·meta가 개발본과 바이트 일치
  - 개인 정보 없음
  - 밖을 가리키는 GUID 참조 없음
- **zip을 직접 풀어 시험**
  - 빈 프로젝트에 임포트(파일 바이트 일치) → 시험 프로젝트에 처음 받는 사람처럼 새로 임포트 → Play 빌드 → Build & Test 3/3 → 제작자가 실제로 쓰는 기믹 많은 아바타에 넣어 업로드(파라미터 224/256) → 인게임
  - README가 바뀔 때마다 다시 묶어 이 과정 반복
- **줄바꿈**
  - 문제: 이 공개 저장소에서 전역 `autocrlf`가 CRLF 파일 4개를 바꿔 패키지와 달라짐 — 첫 커밋 대조에서 발견
  - 해법: `.gitattributes`에 `* -text`를 두고 다시 만듦
  - 결과: blob 93개가 디스크와 바이트 일치
- **해시**: Release zip, 비로그인으로 받은 zip, BOOTH 무료판 다운로드의 SHA-256이 모두 같은지 확인
- **업데이트 알림**
  - 인스펙터가 하루 한 번 GitHub `releases/latest`에 인증 없이 GET → 새 버전 알림(보내는 정보 없음)
  - 첫 Release를 만들 때까지는 꺼 둠

## 함정과 교훈

VRChat·Unity·Modular Avatar로 기믹을 만들 때 다시 만날 만한 것만 선별.

| 증상 | 원인 | 교훈 |
|---|---|---|
| 판이 1 m가 됨 | FX가 크기를 넣은 오브젝트의 `m_LocalScale`을 0~1로 덮어씀 | 애니메이션되는 배율 1 부모와 크기를 가진 자식으로 분리 |
| 판 위치를 세 번 바꿔도 게임에서 그대로 | FX 클립이 위치 `x`만 써서 y·z가 0이 됨 | 위치 커브는 x·y·z 모두 기록. 에디터 확인은 빌드된 클립을 샘플한 뒤에 |
| 음소거를 풀면 시계가 2배로 커짐 | WD off 레이어의 Direct 트리 안에 맨 클립 자식 | Direct 트리 자식은 1D 트리로, 속성 하나에 자식 하나, 가중치 합 1 |
| 크로스페이드로 잔광이 안 생김 | 전이 중에도 출발 상태 트리가 현재 입력으로 다시 평가됨 | 잔광은 AAP 자기참조 smoothing으로 |
| 에디터 Play에서 FX·Driver·Contact·VRC Constraint가 안 돌고 내장 `Head` 송신기도 없음 | 에디터에 Avatars 3.0 런타임 없음 | 처리된 FX를 Animator에 직접 걸고 프레임을 손으로 돌림. 최종 판정은 인게임 |
| 에디터 시뮬레이션은 통과, 인게임에선 버튼이 안 눌림 | 수신기 값을 손으로 넣어 센서 자체는 미검증 | 새 센서는 인게임 디버그로 실제 값부터 확인 |
| "Avatar validation failed"로 빌드 실패 | 새 텍스처의 Streaming Mip Maps 꺼짐(사유는 Editor.log에만) | 모든 텍스처에 Streaming Mip. 빌드 때 만드는 텍스처도 직접 켬 |
| 투사선이 사라짐 | 동적 배칭으로 `unity_ObjectToWorld`가 단위 행렬이 됨 | 오브젝트 행렬로 모양을 펼치는 셰이더엔 `DisableBatching` |
| 시각의 초 자리가 뭉개짐 | Unix 초를 float로 계산 | 시간 계산은 uint |
| 글자가 90°·48° 돌아감 | 머리 위·머리 오른쪽 벡터를 기준으로 씀 | 시선에 직각인 축을 기준으로 |
| 띄운 판이 비스듬히 보면 밀려 보임 | 면 법선 방향으로 띄움 | 눈 쪽으로 띄우면 각도와 상관없이 같은 자리 |
| 월드마다 스캔이 표면을 타거나 안 탐 | 깊이 텍스처는 그림자 있는 Directional Light가 있어야 생김 | 아무것도 비추지 않는 아주 약한 라이트로 깊이 강제 가능 |
| 어둡게 한 효과가 거의 안 보임 | linear 색공간에서 ×0.65는 화면상 약 17% | 화면 밝기 기준으로 `pow(1−k, 2.2)`처럼 보정 |
| 레이더가 경계에서 놓치거나 여러 칸에 잡힘 | Proximity 값에 송신기 반경이 더해짐, 모양 반경 상한 3 m | 수치 모의로 빈틈을 먼저 계산 |
| 루트 scale 1.12 아바타에서 시선점이 10 cm 위 | `ViewPosition`에 스케일이 두 번 곱해짐 | 루트 scale이 1이 아닌 시험 아바타를 넣어 둠 |
| 기즈모가 안 그려짐 | Scene 뷰 Gizmos가 꺼지면 `OnSceneGUI`가 안 불림 | `SceneView.duringSceneGui`에 걸기 |
| Play 빌드에서 이름표가 빠짐 | Play에 들어가면 SDK가 잠깐 로그아웃됨 | 마지막으로 본 이름을 캐시 |
| 번짐에 줄무늬 | 유리만 컬링되면 지난 프레임 GrabPass와 빼짐 | GrabPass를 공유하는 렌더러끼리는 bounds 맞춤 |
| 메뉴 끝에 More가 붙음 | 한 페이지 8개를 넘김 | 처음부터 하위 메뉴로 묶기 |
| 특정 월드에서 손전등이 깜빡임 | 물체당 실시간 라이트 자리 경쟁 | 아바타 쪽 해결 없음 → 알려진 한계로 기재 |
| 자기 손가락으로 눌러도 진동 없음 | 내장 아바타 햅틱이 이 경우 안 울림 | 아바타만으로는 버튼 진동 불가 |
| 공개 저장소 파일이 패키지와 달라짐 | 전역 `autocrlf` | 공개 미러엔 `.gitattributes` `* -text` |
| 바뀐 머티리얼 값을 에디터에서 못 읽음 | Animator가 움직인 값은 `renderer.material`에 없음 | `GetPropertyBlock`으로 읽기 |
